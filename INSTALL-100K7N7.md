# YODAMEN 100K7N7 — Checkbox Multi-Select Dropdown UI

Frontend-only UI refinement for Promotion, Commission, and Incentive Rules.

## Changes
- Personnel multi-select now appears as a compact dropdown field containing checkbox options.
- Service Categories multi-select now appears as a compact dropdown field containing checkbox options.
- Services multi-select now appears as a compact dropdown field containing checkbox options.
- Search remains available inside dropdown menus with more than 6 options.
- Dropdown menu is portaled above modals and may widen for long option labels.
- Selected values are summarized in the closed dropdown field.
- Existing multi-select backend logic and saved data are unchanged.
